# Button

The primary action button; use it for any clickable call-to-action.

```jsx
<Button variant="primary" onClick={submit}>Request a quote</Button>
```

Variants: `primary` (blue, default CTA) · `accent` (lime — reserve for the single most important action per view) · `secondary` (outlined) · `ghost` · `dark` (on light-on-dark bands). Sizes `sm|md|lg`. Pass `leftIcon`/`rightIcon` with a Lucide icon node, `fullWidth` in forms.
