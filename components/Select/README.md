# Select

Ô chọn một giá trị trong danh sách có sẵn: ngành, loại hình, khu vực.

```jsx
<Select label="Industry" defaultValue="paint">
  <option value="paint">Paint & Coatings</option>
  <option value="pvc">PVC & Plastics</option>
</Select>
```

Biến thể và thuộc tính: label · hint · error (viền đỏ) · disabled · children (các option). Mũi tên là icon Lucide chevron-down.
