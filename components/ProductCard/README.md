# ProductCard

Thẻ sản phẩm cho catalogue (163 SP / 6 nhóm ứng dụng).

```jsx
<ProductCard
  category="Ngành sơn · Phụ gia"
  name="Defoamer A-220"
  supplier="Covestro"
  specs={[
    { label: "Liều dùng", value: "0.2 – 0.5 %" },
    { label: "Quy cách", value: "20 kg / can" },
  ]}
  onRequest={() => openQuoteForm()}
/>
```
