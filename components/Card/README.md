# Card

Bề mặt nền trắng, viền nhạt — dùng làm khung cho khối nội dung. Dùng `interactive` khi cả thẻ bấm được.

```jsx
<Card interactive padding="var(--space-5)">…</Card>
```

Biến thể: thẻ thường; `interactive` (rê chuột đổi viền đậm, con trỏ bấm); `padding` đổi đệm trong (mặc định `--space-6`). `accentTop` được nhận nhưng không vẽ gì.
