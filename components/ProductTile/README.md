# ProductTile

Thẻ sản phẩm cho Profile, catalogue hoặc slide — ảnh, tên, mô tả ngắn và 2–3 thông số chính.

```jsx
<ProductTile category="Sơn & Coatings" name="Defoamer A-220" description="Chất phá bọt gốc nước." specs={[["Liều dùng", "0.2 – 0.5 %"]]} />
```

Biến thể: có hoặc không `image` (không có thì hiện khung nền nhạt); `category` và `description` là tuỳ chọn; `specs` là mảng cặp [chỉ tiêu, giá trị].
