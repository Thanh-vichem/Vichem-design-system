# CertificateBadge

Chứng nhận phân phối chính hãng — trục trust-building của Vichem.
6 chứng nhận: Covestro, TotalEnergies Corbion, Tinox, Buhler, IKA, Deco Chemicals.

Dùng `territory` khi chứng nhận có giới hạn phạm vi phân phối.

> Nội dung trong ví dụ là dữ liệu mẫu. Nội dung thật do người dùng cung cấp.

```jsx
<CertificateBadge
  supplier="Buhler"
  since="2024"
  scope="Optical Sorting & Rice Processing Solutions"
  territory="Rice — chỉ Nam VN + ĐBSCL. Plastics — toàn quốc."
/>
```
