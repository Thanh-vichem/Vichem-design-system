# Badge

Nhãn nhỏ trạng thái hoặc phân loại, dùng trong danh sách, bảng và thẻ sản phẩm.

```jsx
<Badge tone="success">Còn hàng</Badge>
<Badge tone="blue">Chính hãng</Badge>
```

Biến thể `tone`: `neutral` (mặc định) · `blue` · `success` · `danger`. Tên cũ `green` và `warning` vẫn chạy: `green` ra như `success`, `warning` ra như `neutral`.
