# HeadingLockup

Tiêu đề mục hai dòng kiểu Profile, in hoa Bebas một màu, có thể kèm số mục — dùng đầu mỗi phần nội dung.

```jsx
<HeadingLockup number="02" line1="Sản phẩm" line2="và giải pháp" />
```

Biến thể: `size` cỡ chữ px (slide 72, A4 42); bỏ `number` thì không có ô số; bỏ `line2` thì chỉ còn một dòng.
