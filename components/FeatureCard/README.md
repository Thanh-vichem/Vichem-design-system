# FeatureCard

Card preset with a tinted icon tile, title and body — for capability and industry grids.

```jsx
<FeatureCard tone="green" icon={<Icon name="leaf" size={20} />} title="Textile">
  Auxiliaries engineered for consistency and lower impact.
</FeatureCard>
```

`tone` `blue|green|neutral` tints the icon tile. Built on Card, so it inherits the hover lift.
