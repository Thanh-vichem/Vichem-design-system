# PartnerLogos

Lưới logo đối tác hoặc nhà cung cấp — các ô bằng nhau, logo căn giữa, giữ màu gốc.

```jsx
<PartnerLogos columns={3} logos={[{ name: "Covestro" }, { name: "Buhler" }, { name: "IKA" }]} />
```

Biến thể: `columns` số cột (mặc định 4); `cellHeight` chiều cao ô px (mặc định 96); mỗi logo có `src` (ảnh) hoặc chỉ `name` (chữ thay thế, ví dụ).
