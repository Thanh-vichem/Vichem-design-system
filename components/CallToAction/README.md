# CallToAction

Lời kêu gọi hành động trên slide, Profile hoặc ảnh chung — dùng khi cần một lối đi rõ ràng (liên hệ, xem thêm).

```jsx
<CallToAction label="Liên hệ tư vấn" detail="08 1790 1790" />
```

Biến thể: `variant` `solid` (khối xanh chữ trắng, mặc định) | `outline` (viền 1px xanh) | `link` (chỉ chữ và mũi tên); `size` cỡ chữ px.
