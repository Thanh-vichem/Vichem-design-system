# SpecTable

Bảng thông số kỹ thuật cho datasheet, Profile hoặc slide — đầu bảng nền nhạt, cột số căn phải.

```jsx
<SpecTable columns={["Chỉ tiêu", "Phương pháp", "Giá trị", "Đơn vị"]} rows={[["Hàm lượng rắn", "ISO 3251", "98.0", "%"]]} numericColumns={[2]} />
```

Biến thể: `numericColumns` chỉ số cột căn phải (mặc định [2]); `fontSize` cỡ chữ px (mặc định 14).
