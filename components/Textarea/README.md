# Textarea

Ô nhập nhiều dòng cho nội dung dài: yêu cầu chi tiết, ghi chú, mô tả.

```jsx
<Textarea label="What do you need?" rows={4} placeholder="Grade, volume, delivery location…" />
```

Biến thể và thuộc tính: label · hint · error (viền đỏ) · rows (mặc định 4) · disabled. Kéo dọc để đổi chiều cao; không có chiều cao cố định.
