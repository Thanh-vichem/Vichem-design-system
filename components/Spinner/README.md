# Spinner

Use it to show that something is loading; use `dots` for an AI answer that is being written.

```jsx
<Spinner variant="ring" label="Đang tải tài liệu" />
```

Variants: `ring` (rotating icon, default) · `dots` (three fading dots, label "Đang trả lời"). Sizes: `size` in px for `ring` (default 20). The label is read by screen readers only.
