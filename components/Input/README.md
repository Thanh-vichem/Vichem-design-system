# Input

Ô nhập một dòng cho thông tin người dùng gõ vào: tên, email, số điện thoại, từ khoá tìm kiếm.

```jsx
<Input label="Work email" type="email" placeholder="you@company.com" hint="Chúng tôi chỉ dùng để trả lời yêu cầu" />
```

Biến thể và thuộc tính: label (nhãn trên) · hint (gợi ý dưới ô) · error (lỗi, viền đỏ, thay cho hint) · leftIcon (tên icon như "mail" hoặc một node icon) · disabled (ô khoá) · containerStyle (style khung ngoài). Các thuộc tính khác của input (type, placeholder, value, onChange, required…) truyền thẳng vào thẻ input.
